# ESP32 Serial Monitor

A modern, web-based serial monitor for ESP32 development, built with Python and NiceGUI.

## Features
- Auto-detect serial ports
- Filter logs by Level, File, and Function
- Auto-reconnect functionality
- Save logs to file
- Modern UI

## Installation (Mac M1 / Linux / Windows)

1. Ensure you have Python installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the application:
```bash
python main.py
```

The interface will automatically open in your default web browser.
